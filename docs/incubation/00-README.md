## 2. TL;DR for the team

- **Program:** Qubic Incubation Program (not the Grants Program). 200B QUBIC treasury, but the fund for a single project is whatever the proposal asks for and the Board approves. For Aigarth Cloud that is **100B QUBIC over four milestone-gated tranches** per `ENDGAME-PROTO-PROPOSAL.md`.
- **Application form:** lives at `qubic.org/incubation-program`. Seven fields: project name, GitHub proposal link, contact email, past projects link, team info, funding request, short description. The detailed proposal lives in **a public GitHub repo** — the form just collects pointers to it.
- **What Qubic reads:** six items — Business Plan, Project Description, Technology Stack, Team Overview, Milestones, Commitment. Each must point to evidence, a decision, or a concrete plan. Vague, padded, generic writing is explicitly rejected.
- **How it gets approved:** three-phase internal review (Incubation Team → Grants Committee → public Discord vote, 55% threshold over five days), then a project manager is assigned and milestones start.
- **How money moves:** Qubic pays on milestone delivery. No upfront payment under any circumstances. Smart contract audit costs: Qubic covers one per project, we cover any extra.
- **Hard restrictions:** no token sale (with narrow exceptions for cross-chain swaps), all code must be open source under Apache 2.0 / GPLv3 / MIT / Unlicense, must commit to one year of maintenance.
- **Our existing position:** the proto-proposal is already written and our repo is already public and operational with 23+ delivery phases shipped. Most of the work is verification, not new writing.
