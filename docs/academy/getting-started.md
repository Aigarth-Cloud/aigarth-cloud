# Getting Started with Aigarth

This is the recommended first path on Aigarth Academy. Five
lessons, ~90 minutes total, by the end you'll have a working
mental model of the platform.

## Who this is for

- Builders about to ship their first ANN
- Operators onboarding to a cluster
- Anyone who wants to understand "what is Aigarth, actually"
  before diving into the [trinary protocol](../architecture-decisions/003-trinary-protocol-v1.md)
  or the [AigarthPool contract spec](../aigarthpool/contract.md)

## How to use it

Read in order. Each lesson is short, opinionated, and links
out to the deeper docs where it matters. If you already know a
topic, skip it — the lessons are designed to stand alone.

## The lessons

1. **Product Requirements Document** — the vision, the users, the
   surfaces, the success metrics. 12 min.
2. **System Architecture** — the service map, the data flow, the
   deployment topology. 10 min.
3. **Data Model** — the 82+ domain objects and their owning
   services. 15 min.
4. **Developer Guide** — local dev setup, commands, common
   gotchas. 7 min.
5. **API Specification** — endpoint contracts, error format,
   auth, rate limits. 12 min.
